# portion

**Category:** spell

**OLD description:** none — new field

**NEW description (generated):**

A single gesture splits the mass. It looks like the object is being cut by an unseen knife, dividing one piece into two, two into four, and so on. The new parts are equal in size and weight. If you have enough mana, the division is precise; with less, one side might be slightly larger. It works for a single loaf of bread or a large cake, making sure everyone gets the same share.
