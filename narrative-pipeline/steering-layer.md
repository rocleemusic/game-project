# The Steering Layer (the arc doc)

One document per arc. An arc is a span of reshuffle-lives, a season. The arc doc is written before any scene generates, and it is what the orchestrator hands each worker as prepared context, the same job BioWare's half-hour theme-and-tent-pole one-pager did for a full team (storytelling-lessons-bioware.md). Its structure is ported from the campaign doc that ran this exact role at a live D&D table (D&D arc doc: CAMPAIGN_ARC.md). The generation procedure makes consistent, non-scripted content, but nothing tells it where the whole arc is going; this doc does. Five fields. The fillable version is `templates/arc-doc-template.md`.

**World Truths.** Three to five hidden facts about the world the arc steers toward. Example shape for this game: "a bond re-forms across lives as a thing tended, not a memory stored." No scene states one. Every scene serves one. The player starts from zero and assembles each truth from the biased, partly contradictory accounts different souls give (npcs-with-agency-80-days.md). World Truths are not canon_flags: canon_flags enforce consistency, a new fact must not contradict a locked one; World Truths steer direction, they tell Intake which fact to plant next (D&D arc doc: World Truths). The game's philosophical layer lives inside this field, never spoken aloud, answered only by how the player spends their time (D&D arc doc: Philosophical Thread; brennan-philosophy-as-foundation.md).

**The Arc Question.** One per arc. Example: "across these three festival-years, does this soul become someone the player tends, or someone the player releases?" It gives every per-scene delta a direction. The prior-art evidence is blunt: the campaign arc that had a question felt like it was building, and the stretch without one read as "and then, and then" (D&D arc doc: NARRATIVE_NOTES.md). The question is answered by play. It is never resolved in dialogue and never tested for comprehension. One question only; a second question competing for the delta's direction is over-authoring, and the philosophical layer folds into the World Truths instead (D&D arc doc: Philosophical Thread).

**Soul Arc Spines.** One line per soul, from X to Y across the arc's reshuffle-lives: Mara, from keeper to giver (D&D arc doc: Arc Spines). This is a human note in the arc doc. It is not a persona_card field and not a machined generation input. It gives you and the Narrative Architect a one-line read on where a soul's content is heading, and it guides hand-seeding: which of the soul's facets you choose to surface early versus late, so Mara's life-one pool and her life-three pool are not interchangeable. It never gates content on reaching Y, and it never drives the bond score toward a destination: the deepest bond stays emergent (see [`../gdd/06-world-and-progression.md`](../gdd/06-world-and-progression.md)), and a soul whose spine points at giving can still land anywhere on the festival-outcome spectrum (see [`../gdd/03-core-loop.md`](../gdd/03-core-loop.md)). *(An earlier community/diffuse/solitary-release endings taxonomy was superseded by that spectrum — preserved in [`../resources/parking-lot.md`](../resources/parking-lot.md), not deleted.)* Because it is a human note rather than a generation parameter, it cannot mechanically script toward Y, so it needs no automated guard; where a spine is sanity-checked is the human gate (`review.md`), not the Verifier.

**Threads to Not Drop.** A staleness list. Each open thread carries a last-moved counter; any thread untouched for six scenes biases the next scene request toward moving it. Move means new information on the thread, not resolution (D&D arc doc: Threads to Not Drop). The cap counts scenes, tuned to player memory rather than simulated time (emergent-storytelling-the-sims.md), and it supplies the "not sent there lately" axis the errand generator reads (heavens-vault-detective-story.md). A thread shown at the edge of frame must stay interpretable and must eventually move; shown-then-abandoned is a defect.

**What This Arc Is NOT.** Explicit anti-goals, so an omission is a decision instead of a silent gap (D&D arc doc: What This Season Is NOT). The list includes omitted verbs, because the actions we leave out characterize this world as much as the ones we keep (storytelling-with-verbs.md). At Intake the list is a filter: a scene brief that drifts into an anti-goal is rerouted before it reaches prose.

---

**The steering layer steers content, never a feeling.** Every field is a world fact, a direction, a human note, or a counter. A World Truth phrased as a player outcome ("the player feels the bond persists") is rejected at the doc stage. See the steering guard in `guardrails.md`.

**Specify the invariant, not only the variable.** When any field hands down an axis that *varies* — a register spread, a tier range, a stance scale — it must also state what holds **constant** across that axis. A spread given without its invariant is an underspecification, and the crew will resolve it in whichever direction the words happen to lean. The 2026-07-25 proof run produced this defect twice, one level apart: first a spread was passed as a binary switch and both arms missed the target; then the spread was passed correctly but nothing said *warmth does not move along it*, so the Architect encoded it right, the Verifier passed every sub-check, and the resulting line was still cold. Only the human gate caught it. The rule generalises past registers: **whatever you let vary, name what must not.**
