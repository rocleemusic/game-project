# Ilsa — Blacksmith: thread registry (life one)

**Soul:** [`ilsa.md`](ilsa.md) — the card, which outlives this file.
**Role this life:** Blacksmith. Role-goal: forge the Lantern Arch centerpiece.
**Status: five ratified, three deferred (one of them `pair-`), two rejected.** Authored 2026-08-09 as candidates for Roc's gate, after Toby's registry set the format ([`toby-baker-threads.md`](toby-baker-threads.md)). Roc's gate rulings of 2026-08-09 applied the same day; the second pass ratified the survivors, un-deferred `ilsa-blood-claims` (its blocker was not real — see the row), and added two new rows, each **Reveals** column naming the distinct essence facet it opens — no two rows reveal the same thing, per the bar Toby's registry set. One thread already has a downstream spec ([`../lantern-projects/v01/threads/ilsa-kin-no-show.md`](../lantern-projects/v01/threads/ilsa-kin-no-show.md)), authored before this registry existed; its row is marked.

**What a thread is here:** an open question this life keeps feeding. Stated up front, as on Mara's registry: **Ilsa's role is plot-inert on purpose** — her card names this soul "the pipeline's proof that a role which does not generate the arc still works." Her authored engine is the **family-pressure pool** ([`../narrative-pipeline/arc-festival-slice.md`](../narrative-pipeline/arc-festival-slice.md)) — other people's behavior, accumulated small absence — which is per-life pressure (this life's Bram, this week's raising) without being role-made. Each row says which engine feeds it. Two rows sit deferred because the family pool's harder rows need family members canon does not yet supply (`ilsa-blood-claims` left that block 2026-08-09 — the word-sent pattern carries its ask without staging anyone); the third deferral is the cross-soul `pair-` row, owned by `toby`.

**What a thread is, for the purposes of this list.** An open question the story keeps *feeding*, never one it resolves. It moves on new information. It is not the arc: the arc is what the threads add up to, and it resolves in the player's head rather than in a counter.

> **Ruling 2026-08-09 (Roc) — a role-goal is a situation, not a thread.** The feast, the centerpiece and the tonic are the **pressure** this life's deal manufactures; they belong in `delta_situation`, where they are uncapped and stateful, and they feed threads rather than occupying a row. The one licensed exception is a row that states the *tension between the want and the role-goal* rather than the goal itself — the arc doc's `toby-feast-short` is phrased exactly that way, "the Baker's feast can't be finished alone (the Giver's want × role-goal tension)". A row that merely restates the role-goal is rejected.
