## Rules

**Read a synthesis artifact before reading a track.** The tracks are evidence. The synthesis folder is the answer. Slurping `narrative/` costs a full context window and mostly repeats what `voice-style-guide.md` already resolved.

**A ruling here can be superseded and the note stays.** When a project ruling reverses a knowledge-base recommendation, that note gets a supersession banner the same session — the banner rule in `commands/gdd-sync.md`. The note is not deleted. Its comparison work usually stays useful.

**Coverage ratings are a judgment about craft available, not note count.** Five thin notes on a hole can still be `●○○`.
