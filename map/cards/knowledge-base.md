## What it is
Distilled *external* reference — Frieren analysis, the dialogue corpus, Myst docs,
point-and-click and UI-juice research. Explicitly not the project's own design
decisions; those live in `gdd/` (`gdd/CONTEXT.md` §Related). Read `synthesis/`
before any track (`CONTEXT.md` §Where things live).

## Doors
- `knowledge-base/CONTEXT.md` — the index
- `knowledge-base/synthesis/` — the distillations tracks start from
- `knowledge-base/dialogue-corpus/` — the 4,735-turn corpus behind the register's numbers

## Hits
Pipeline voice work: `narrative-pipeline/register.md` names
`knowledge-base/synthesis/voice-style-guide.md` as the in-fiction voice authority
and the corpus as the cadence source. When a ruling reverses a recommendation here,
the doc gets a supersession banner the same session (the banner rule,
`gdd/CONTEXT.md`).

## Does not hit
Engine decisions, despite appearances: `knowledge-base/narrative/ink-unreal-integration.md`
still ranks inkcpp first, and that recommendation is superseded — the ink runtime is
Inkpot, ruled 2026-08-02 (`CONTEXT.md` §The Unreal side). Its comparison table
remains useful; its conclusion is dead. A cold reader taking this folder as current
policy imports overturned calls.
